Your task is to transform this application into a subscription-based platform focused on long-term customer retention.

Requirements:

- Add secure user registration and login.
- Support email/password authentication.
- Persist user sessions.
- Add password reset functionality.
- Add optional two-factor authentication.

- Welcome message
- Account information
- Subscription status
- Remaining monthly credits (if applicable)
- Storage usage
- Recent activity
- Favorite items
- Quick actions

- Folder organization
- Search
- Favorites
- Tags
- Archive
- Soft delete with restore
- Version history

## User Preferences
Save user settings including:
- Theme
- Language
- Default export options
- Notification preferences
- Dashboard layout

Free
- Limited monthly usage
- Basic storage

Pro
- Higher monthly usage
- More storage
- Priority processing
- Advanced organization features

Business
- Team workspaces
- Shared folders
- Role-based permissions
- Audit logs
- Unlimited storage (or configurable)

## Billing

- Monthly billing
- Annual billing
- Upgrade/downgrade
- Cancel/resume
- Billing history
- Invoices
- Trial support
- Webhook handling

- Personalized onboarding checklist

- In-app notifications

- User management
