==================================================
ACCOUNT MATCHING
==================================================

Match existing accounts using multiple signals:

1. normalized institution
2. account type
3. last four digits
4. employer or plan sponsor
5. plan name
6. account nickname
7. statement date
8. prior balance proximity

Use a match score.

Example:

function scoreAccountMatch(imported, existing) {
  let score = 0;

  if (
    imported.institution.normalizedName &&
    imported.institution.normalizedName === existing.institution.normalizedName
  ) score += 30;

  if (
    imported.account.lastFour &&
    imported.account.lastFour === existing.account.lastFour
  ) score += 40;

  if (
    imported.account.accountType &&
    imported.account.accountType === existing.account.accountType
  ) score += 15;

  if (
    imported.planName &&
    imported.planName === existing.planName
  ) score += 10;

  if (
    imported.employer &&
    imported.employer === existing.employer
  ) score += 5;

  return score;
}

Suggested behavior:
- score 80 or greater: strong existing-account match
- score 50–79: ask user to confirm match
- below 50: suggest creating a new account

Never merge accounts based only on institution name.
