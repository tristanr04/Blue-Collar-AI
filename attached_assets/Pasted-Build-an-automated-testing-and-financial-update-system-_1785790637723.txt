SECTION 2 — AUTOMATED FINANCIAL PROFILE UPDATES
==================================================

After a real user confirms a scanned document, automatically update the appropriate financial records.

Paystub:
- Add to paycheck history
- Update income averages
- Update regular, OT, DT, per diem, gross, deductions, and net-pay history
- Ask before changing the user’s default pay assumptions

Banking:
- Match an existing account using institution, type, and last four digits
- Update current and available balances
- Update liquid cash, emergency fund, and net worth
- Never duplicate an existing account silently

Credit cards:
- Update balance, limit, APR, minimum payment, and due date
- Recalculate utilization and monthly obligations

Loans:
- Update principal balance, APR, payment, due date, and remaining term
- Recalculate debt totals, payoff estimates, and DTI

Mortgage:
- Update balance, payment, escrow, rate, and due date
- Recalculate housing expense, total debt, and home equity

Bills:
- Match recurring providers
- Update amount and due date
- Detect bill increases or decreases
- Recalculate monthly expenses
- Ask before replacing a user-created budget target

Investments and retirement:
- Update balances, cash, margin, contribution rates, employer match, and vested balances
- Recalculate investment totals, retirement totals, and net worth

Every confirmed import must create a change-history record:

type FinancialChangeRecord = {
  id: string;
  timestamp: string;
  sourceDocumentId: string;
  sourceFilename: string;
  destinationSection: string;
  recordId: string;
  field: string;
  oldValue: unknown;
  newValue: unknown;
  userConfirmed: boolean;
};

Add:

- Undo last import
- View import history
- Restore previous value
- Update existing account
- Create new account
- Reject update
- Ignore older statement

Never overwrite newer data with an older statement without explicit approval.

After every successful update, automatically recalculate:

- Weekly income
- Monthly income
- Monthly expenses
- Minimum debt payments
- Free cash flow
- Credit utilization
- Debt-to-income ratio
- Liquid cash
- Emergency-fund coverage
- Investments
- Retirement
- Home equity
- Net worth
- Financial Health Score
- Scenario Builder defaults
- AI assistant financial context
